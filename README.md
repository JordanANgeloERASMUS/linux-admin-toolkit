
# Linux Administration Toolkit

A practical Linux administration project containing
Bash scripts for system information reporting and
basic disk monitoring.

Developed as part of my IT Engineering and Cloud &
DevOps learning journey.

## Features

- System information reporting
- CPU and memory information
- Disk usage monitoring
- Linux command reference
- Basic system troubleshooting

## Requirements

- Linux operating system
- Bash
- Standard Linux utilities

## Installation

Clone the repository:

    git clone YOUR_REPOSITORY_URL

Enter the project:

    cd linux-admin-toolkit

Make scripts executable:

    chmod +x scripts/*.sh

## Usage

System information:

    ./scripts/system-info.sh

Disk monitoring:

    ./scripts/disk-check.sh
